# YUSEI OKARUN — DAN DA DAN Anime Archive

A static GitHub Pages website inspired by the visual language of DAN DA DAN:
- black / white / blood-red palette
- manga-style typography
- glitch/noise texture
- personal anime watchlist
- DAN DA DAN Seasons 1 & 2 YouTube buttons
- Season 3 update panel
- character section

## Deploy on GitHub Pages

1. Create a repository, e.g. `yusei-okarun`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Set **Deploy from branch** → `main` → `/root`.
5. Save and open the generated GitHub Pages URL.

The YouTube buttons intentionally open YouTube search results for official DAN DA DAN / Crunchyroll material rather than hosting or redistributing episodes.
